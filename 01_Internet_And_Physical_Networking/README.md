If time is short, read the study notes and their diagrams, then answer the essential questions. The optional material adds depth where it helps explain a real situation; there is no requirement to complete every linked resource.

By the end, you should be able to:

- Explain how an Internet request travels beyond the Wi-Fi access point through independently operated networks.
- Distinguish packets, frames and signals, and identify what a router changes at each hop.
- Separate bandwidth, throughput, latency, RTT, jitter and loss when diagnosing “slow Internet.”
- Compare a hub, switch and router, and explain the default gateway's role.
- Explain why data centres need more than servers and how a CDN reduces repeated origin traffic.
- Distinguish a region, availability zone, Local Zone and edge location without relying on changing provider counts.

The lecture uses laptops in Pune and overseas, submarine cables, an EC2 instance in Oregon, and course notes served through a CDN. The notes retain these teaching anchors while correcting simplified claims about IXPs, hops and cache behaviour.
